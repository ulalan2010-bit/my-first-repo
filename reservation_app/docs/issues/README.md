# docs/issues/

GitHub Issue駆動開発フロー(`.claude/skills/issue-*`, `.claude/skills/issue-flow`)が生成する成果物置き場。

Issue番号ごとにディレクトリを作り、各工程の成果物を置く。

```
docs/issues/<Issue番号>/
  requirements.md   # 要件定義(issue-requirements)
  design.md         # 設計(issue-design)
  review.md         # レビュー指摘(issue-review, 追記式)
  test-report.md    # テスト結果(issue-test, 追記式)
```

フロー全体の説明は `.claude/skills/issue-flow/SKILL.md` を参照。
