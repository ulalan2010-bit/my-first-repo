# 10. 機能要件 — 電子カルテ（MedChart）

## 10.1 設計原則

- **可読性・俯瞰性**を最優先
- **入力負担の最小化**
- **医療安全**（アレルギー・禁忌の強調）
- **監査証跡**（更新履歴の記録）

詳細は [設計原則](06_設計原則.md) を参照。

## 10.2 画面構成

| ID | 要件 |
|---|---|
| FR-EMR-001 | 左サイドバー：メニュー、最近開いたカルテ（ログイン職員単位） |
| FR-EMR-002 | 上部：患者ヘッダー（常時表示） |
| FR-EMR-003 | 3カラム：左=受診履歴、中央=SOAP、右=検査・オーダー |

## 10.3 患者ヘッダー

| ID | 要件 |
|---|---|
| FR-EMR-010 | ID、氏名、カナ、性別、生年月日、年齢、主病名、担当医、アレルギー、禁忌を表示 |
| FR-EMR-011 | アレルギー・禁忌を色付きバッジで強調 |
| FR-EMR-012 | 編集ボタンでヘッダー編集 |
| FR-EMR-013 | 最終編集日時・編集者を小さな文字で表示 |
| FR-EMR-014 | 1項目でも変更があれば、ヘッダー最新内容全体を編集日の経過記録として保存 |

## 10.4 経過記録（SOAP）

| ID | 要件 |
|---|---|
| FR-EMR-020 | SOAP形式（S/O/A/P） |
| FR-EMR-021 | 前回記録コピー、定型文テンプレート |
| FR-EMR-022 | 更新履歴（作成者・更新者・日時） |

## 10.5 受診履歴・カレンダー

| ID | 要件 |
|---|---|
| FR-EMR-030 | 受診日・診察方法（クリニック/巡回/訪問/オンライン）バッジ付き一覧 |
| FR-EMR-031 | 受診登録。登録後カレンダー・一覧に反映 |
| FR-EMR-032 | 受診日クリックでその日の経過記録・検査・オーダーを表示 |
| FR-EMR-040 | 患者検索：名前・ID・受診日 |
| FR-EMR-041 | 本日の予定：カレンダーで日付選択 → 診察方法別に受診患者一覧 |

## 10.6 予約情報の引き継ぎ

| ID | 要件 |
|---|---|
| FR-EMR-050 | 診療予約時に入力された患者情報（本名・生年月日・住所・本人確認書類等のPII、家族人数等）は、電子カルテの患者ヘッダーへ再入力なしで引き継がれる |
| FR-EMR-051 | オンライン診療・新得時間外外来診療の予約時に入力された医療問診票（[機能要件9.14](09_機能要件_診療予約.md#914-医療問診票オンライン診療新得時間外外来診療)）の内容は、当該受診日の経過記録（S: Subjective）に自動反映される |
| FR-EMR-052 | 引き継がれた内容は医師・職員が確認・修正できる |

## 10.7 外部文書のスキャン・サマリー化

| ID | 要件 |
|---|---|
| FR-EMR-053 | 血圧・検査結果・診療情報提供書等の紙資料を撮影すると、画像をスキャンとして保存するとともに、内容の要約（サマリー）を生成し経過記録に追加する |
| FR-EMR-054 | 生成されたサマリーは医師・職員が内容を確認・修正した上で記録に反映する（自動確定はしない） |
| FR-EMR-055 | 元の撮影画像はサマリーとあわせて保管し、いつでも参照できる |

## 10.8 診断書・紹介状の自動作成

| ID | 要件 |
|---|---|
| FR-EMR-056 | 医師が経過記録に受診内容を記録すると、その内容をもとに診断書・紹介状の下書きを生成できる |
| FR-EMR-057 | 「診断書作成」「紹介状作成」をクリックすると、生成された文章が経過記録に記録として残る |
| FR-EMR-058 | 診断書・紹介状は日本語・英語を併記する |
| FR-EMR-059 | 診断書には、処方した内容（[10.11](#1011-処方点滴オーダーセット処方)の処方箋の内容）を併記する |
| FR-EMR-060 | 紹介状は、一般的に必要な内容（患者情報・現病歴等）と疑っている診断名に加え、下記の定型文の間に経過記録の内容から要約した依頼理由を挿入して生成する。冒頭：「平素より大変お世話になっております。当院時間外受診となりました上記の方ですが、」／末尾：「ご多忙のおり大変恐縮ですが何卒ご高配のほどお願い申し上げます。」 |
| FR-EMR-061 | 医師が生成内容を承認すると、同一内容を印刷用のWordファイル形式（.docx）で出力できる |
| FR-EMR-062 | 承認前の下書き段階では、医師はサマリー・診断書・紹介状の内容を自由に編集できる |
| FR-EMR-063 | 診断書・紹介状・[10.7](#107-外部文書のスキャンサマリー化)のサマリー生成にAI（自然言語生成）を利用する場合は、患者情報を外部の一般公開AIサービスに送信せず、セキュリティが担保された閉域環境のAIを利用する（[非機能要件](12_非機能要件.md)参照） |

## 10.9 検査・処置オーダー（実施内容）

| ID | 要件 |
|---|---|
| FR-EMR-064 | カルテの「実施内容」から検査・処置のオーダーを選択できる |
| FR-EMR-065 | 検体検査は「血液ガス／血液検査／尿検査／迅速検査／培養検査／病理検査」に分類し、各分類の中からさらに具体的な検査項目を選択できる |
| FR-EMR-066 | 画像検査は「単純写真／CT／MRI／超音波」に分類し、各分類の中から撮影部位を選択できる |
| FR-EMR-067 | 生理検査は検査項目を選択できる（具体的な項目リストは別途確定する。未確定事項） |
| FR-EMR-068 | 処置は「縫合／固定」等の項目から選択できる |
| FR-EMR-069 | 縫合を選択した場合、診療報酬（保険点数）に関連する事項（創の部位・長さ等）を書き込める欄を設ける |
| FR-EMR-070 | 検体検査・画像検査の分類・項目・部位は、システムエンジニアがマスタ管理画面から追加・削除できる |
| FR-EMR-071 | 処置の項目も同様にシステムエンジニアがマスタ管理画面から追加・削除できる |

## 10.10 診療報酬点数の参考算出

| ID | 要件 |
|---|---|
| FR-EMR-072 | 診療報酬点数表に関連するページを撮影して入力すると、該当する処置・検査等のおおよその点数を表示する（参考値であり、正式なレセプト算定を代替しない） |

## 10.11 処方・点滴オーダー（セット処方）

| ID | 要件 |
|---|---|
| FR-EMR-073 | 経過記録から薬剤を選択すると、処方内容が経過記録に記録される |
| FR-EMR-074 | 医師が処方内容に同意（承認）すると、処方箋として印刷用のWordファイル形式で出力できる |
| FR-EMR-075 | 処方は自由記載に加え、あらかじめ登録された「セット」からまとめて選択できる。セットは上気道炎／インフルエンザ／喘息／胃腸炎／解熱・鎮痛剤／アレルギーの6種を用意する |
| FR-EMR-076 | 点滴も同様に、経過記録から選択すると記録に残り、承認後に印刷用のWordファイル形式で出力できる。セットはインフルエンザ／喘息／胃腸炎／解熱・鎮痛剤／アレルギーの5種を用意する |
| FR-EMR-077 | 各セットに含まれる採用薬剤は、システムエンジニアがマスタ管理画面からあらかじめ登録する |
| FR-EMR-078 | セット自体の追加・削除も、システムエンジニアがマスタ管理画面から簡単に行える |

## 10.12 福祉タクシー利用の記録

| ID | 要件 |
|---|---|
| FR-EMR-079 | 患者が福祉タクシーを利用した場合、経過記録に「福祉タクシー利用」の記録を追加できる |
| FR-EMR-080 | 本記録は利用の事実を残す簡易な記録（メモ／タグ）にとどめ、福祉タクシー予約システムとのデータ連携・共有は行わない（[CLAUDE.md](../../CLAUDE.md)、[スコープ2.2](02_スコープ.md#22-対象外out-of-scope現時点)参照） |
