# 3. 用語定義

| 用語 | 説明 |
|---|---|
| アクティベート | 職員が予約枠を公開し、外部から予約可能にすること |
| インアクティベート | 枠を非公開にすること（デフォルト） |
| PII | 個人識別情報（本名、生年月日、住所、本人確認書類（保険証／運転免許証／パスポート）等） |
| 非提示オプション | PIIを情報システムに一切提示しないことを患者が選択するオプション。選択すると[匿名予約](09_機能要件_診療予約.md#93-匿名予約完全匿名受診希望者向け)フローに進む |
| 匿名予約 | 非提示オプション選択者向けの予約方式。データ管理手数料等を支払うことで、ニックネームとメールアドレスのみで予約を確定できる |
| SOAP | 経過記録形式（Subjective / Objective / Assessment / Plan） |
| ニコニコドック | 検査ドック枠。脳／全身炎症・がん／乳がん／前立腺の4区分をそれぞれ独立した枠として提供し、いずれか1区分が予約されると同日の残り3区分は自動的にインアクティベートされる |
| 新得時間外外来診療 | 新得クリニックの時間外来院診療枠（v1.0時点の名称は「新得クリニック時間外（来院）」） |
| 繁忙期 | 時間外外来診療の需要が高まる期間（12/15–4/10、4/25–5/10、7/20–8/20、9/10–9/25）。v1.0時点の名称は「季節期間」 |
| 搬送 | 患者搬送の予約枠種別。車種（カローラクロス／シエンタ／ノア）ごとに独立した枠を持つ |
| システムエンジニア | 予約枠種別・下位項目（検査区分・車種等）のマスタ管理、および全予約データの閲覧（自動パージ済みデータを除く）を行う専用ロール |
| 受診完了 | 職員が受診を記録した状態。PII保持期間の起算点 |
