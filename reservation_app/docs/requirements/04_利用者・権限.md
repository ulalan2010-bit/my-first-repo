# 4. 利用者・権限

| 利用者 | 診療予約 | 電子カルテ |
|---|---|---|
| 一般患者 | ○ Web予約（公開中の枠と自分の予約のみ閲覧可） | — |
| 職員 | ○ 枠公開・紙取込・受診完了・全予約のニックネーム一覧閲覧・予約詳細確認 | ○ 記録・編集・検索 |
| システムエンジニア | ○ 全予約データ閲覧・予約枠種別／下位項目のマスタ管理 | — |

*職員画面はログインで保護（現状：パスコード `staff`）。システムエンジニア画面は職員画面とは別のアクセス制御で保護する。*

## ロールごとの閲覧範囲

| ロール | 閲覧できる範囲 |
|---|---|
| 一般患者 | 現在公開されている予約枠、および自分自身が登録した予約内容のみ。他の患者のニックネーム・予約は閲覧不可 |
| 職員 | 全予約のニックネーム一覧。予約時間をクリックすると当該予約の登録内容を確認可能 |
| システムエンジニア | 全予約データ（PIIを含む） |

**共通ルール**：受診完了から2ヶ月が経過し自動パージされたPIIは、職員・システムエンジニアを含むいずれのロールからも参照できない（ロールに関わらない物理削除）。詳細は[機能要件 — 診療予約・患者情報管理](09_機能要件_診療予約.md)を参照。

## 将来の検討（職種別権限の細分化）

現状は「職員」を単一ロールとして扱うが、将来的には以下のような細分化が考えられる。

| 職種 | 想定権限 |
|---|---|
| 医師 | 患者情報閲覧・編集、経過記録作成、診断名登録、記録確定・訂正 |
| 看護師 | 患者情報閲覧、許可範囲の編集、経過記録作成、下書き保存（確定権限は施設設定による） |
| その他職員 | 必要な範囲の患者情報閲覧、基本情報登録。診療記録の確定は原則不可 |
| システム管理者 | ユーザー・権限・システム設定・監査ログ・バックアップ管理（システムエンジニアのマスタ管理権限とは別に、将来的にアカウント管理等を担う想定） |
