# 8. 画面一覧

## 診療予約（yoyaku-kanri）

| ID | 画面 | パス | 利用者 |
|---|---|---|---|
| CL-01 | トップ | `/` | 共通 |
| CL-02 | 職員ログイン | `/staff/login.html` | 職員 |
| CL-03 | 枠オープン | `/staff/slots.html` | 職員 |
| CL-04 | 紙予約取込 | `/staff/paper-intake.html` | 職員 |
| CL-05 | 予約一覧・受診完了 | `/staff/reservations.html` | 職員 |
| CL-06 | 患者予約 | `/patient/reserve.html` | 一般 |

**CL-05（予約一覧・受診完了）**：全予約のニックネームを一覧表示する。予約時間をクリックすると、その予約の登録内容（本名・生年月日・住所・本人確認書類の写真等）をモーダル等で確認できる。ただし受診完了から2ヶ月が経過し自動パージされた予約のPIIは表示しない（ニックネーム・予約種別・日時のみ残る）。

**CL-06（患者予約）**：患者が閲覧できるのは、現在公開されている予約枠と、自分自身が登録した予約内容のみ。他の患者のニックネーム・予約内容は一切表示しない。

## システムエンジニア（yoyaku-kanri）

| ID | 画面 | パス | 利用者 |
|---|---|---|---|
| SE-01 | 全予約データ閲覧 | `/se/reservations.html` | システムエンジニア |
| SE-02 | 予約枠種別マスタ管理 | `/se/master.html` | システムエンジニア |
| SE-03 | 通知設定 | `/se/settings.html` | システムエンジニア |
| SE-04 | 検査・処置マスタ管理 | `/se/exam-master.html` | システムエンジニア |
| SE-05 | 処方・点滴セットマスタ管理 | `/se/drug-set-master.html` | システムエンジニア |

**SE-01**：全予約データ（PIIを含む）を閲覧できる。ただし受診完了から2ヶ月経過後に自動パージされたPIIは、このロールからも例外なく参照できない（パージは物理削除のため）。

**SE-02**：予約枠種別（オンライン診療／新得時間外外来診療／ニコニコドック／搬送 等）と、その下位項目（ニコニコドックの検査区分、搬送の車種等）、時間ルールを、コード変更なしに追加・編集・無効化できる。種別自体の新規追加も可能とする。操作は監査ログに記録する。

**SE-03**：予約確定メッセージに表示する緊急連絡先電話番号など、通知に関わる設定項目をコード変更なしに変更できる（[機能要件9.11](09_機能要件_診療予約.md#911-予約確定時の連絡)参照）。操作は監査ログに記録する。

**SE-04**：検体検査（血液ガス／血液検査／尿検査／迅速検査／培養検査／病理検査）・画像検査（単純写真／CT／MRI／超音波とその撮影部位）・生理検査・処置の分類と項目を追加・削除できる（[機能要件10.9](10_機能要件_電子カルテ.md#109-検査処置オーダー実施内容)参照）。

**SE-05**：処方セット（上気道炎／インフルエンザ／喘息／胃腸炎／解熱鎮痛剤／アレルギー）・点滴セット（インフルエンザ／喘息／胃腸炎／解熱鎮痛剤／アレルギー）に含める採用薬剤を登録し、セット自体の追加・削除もできる（[機能要件10.11](10_機能要件_電子カルテ.md#1011-処方点滴オーダーセット処方)参照）。

## 電子カルテ（emr）

| ID | 画面 | 機能 |
|---|---|---|
| EMR-01 | カルテ本体 | 3カラム、患者ヘッダー、SOAP |
| EMR-02 | 本日の予定 | 受診カレンダー・診察方法別一覧 |
| EMR-03 | 患者検索 | 名前・ID・受診日 |
| EMR-04 | ヘッダー編集 | モーダル編集・経過記録連動 |
| EMR-05 | 検査・処置オーダー | 検体検査／画像検査／生理検査／処置の選択、診療報酬点数の参考表示 |
| EMR-06 | 診断書・紹介状作成 | 経過記録からの下書き生成・編集・承認、日英併記、Word出力 |
| EMR-07 | 処方・点滴オーダー | セット選択・自由記載、承認後Word出力 |

## 患者ヘッダー（全画面共通・EMR-01上部）

カルテを開いている間、画面上部に常時表示（患者取り違え防止）。

表示項目：ID、氏名、カナ、性別、生年月日、年齢、主病名、担当医、アレルギー、禁忌（アレルギー・禁忌は色付きバッジで強調）。編集ボタンから更新でき、最終編集日時・編集者を小さな文字で併記する。
