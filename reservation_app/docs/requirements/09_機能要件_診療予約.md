# 9. 機能要件 — 診療予約・患者情報管理

## 9.1 予約枠管理（職員）

| ID | 要件 |
|---|---|
| FR-CL-001 | 月次カレンダーで日付を選択し、その日の枠一覧を表示する |
| FR-CL-002 | 枠種別は4種（下表：オンライン診療／新得時間外外来診療／ニコニコドック／搬送） |
| FR-CL-003 | すべての枠はデフォルト非公開 |
| FR-CL-004 | 枠ごと、または種別ごとに一括アクティベート/インアクティベート可能 |
| FR-CL-005 | 公開された枠のみ予約可能 |
| FR-CL-006 | ニコニコドックは脳／全身炎症・がん／乳がん／前立腺の4区分を、それぞれ独立した予約枠として管理する |
| FR-CL-007 | ニコニコドックはいずれか1区分が予約されると、同日の残り3区分の枠を自動的にインアクティベートする |
| FR-CL-008 | 搬送枠は車種（カローラクロス／シエンタ／ノア）ごとに独立した予約枠として管理する |
| FR-CL-009 | 枠種別・時間ルール・下位項目（ニコニコドックの検査区分、搬送の車種等）は、システムエンジニアが[マスタ管理画面](08_画面一覧.md)から追加・編集・無効化できる（コード変更なしで対応できる設計とする）。枠種別自体の新規追加も同様に可能とする |

**枠種別と時間ルール**

| 種別 | 時間ルール |
|---|---|
| オンライン診療 | 毎日 14:00–21:00、毎時 :00–:20 |
| 新得時間外外来診療 | 毎時 :30–:50。土日月 6–10時、金土日 17–23時。繁忙期（12/15–4/10、4/25–5/10、7/20–8/20、9/10–9/25）は毎日 6–8時・17–23時も適用。**繁忙期に限り、上記に加えて毎時 :00–:20 の枠も追加する** |
| ニコニコドック | 毎日 9:00–18:00。脳／全身炎症・がん／乳がん／前立腺の4区分をそれぞれ独立した枠として提供（FR-CL-006・FR-CL-007参照） |
| 搬送 | 毎日 5:00–22:00、30分刻み。カローラクロス／シエンタ／ノアの3車種から選択（FR-CL-008参照） |

> 「新得時間外外来診療」はv1.0時点の「新得クリニック時間外（来院）」、「繁忙期」は同「季節期間」の呼称変更。

## 9.2 患者Web予約

| ID | 要件 |
|---|---|

| FR-CL-011 | フロー：①診療種別選択 → ②時間枠選択 → ③同意チェック（[9.4 同意書](#94-同意書受診種別ごと)） → ④匿名予約に関する追加同意（非提示オプション選択者のみ、[9.3 匿名予約](#93-匿名予約完全匿名受診希望者向け)） → ⑤登録情報入力 → ⑥確認・確定 |
| FR-CL-012 | 入力項目（下表） |
| FR-CL-013 | 注意書きを必ず表示（家族同時受診の上限、予約料、キャンセルポリシー等。詳細はFR-CL-017〜020および各診療種別の同意書に集約） |
| FR-CL-014 | 対象の診療種別に紐づく同意書の項目にすべてチェックしない限り、登録情報入力画面へ進めない |
| FR-CL-015 | 患者が閲覧できるのは、現在公開されている予約枠と、自分自身が登録した予約内容のみ。他の患者のニックネーム・予約内容は一切表示しない |
| FR-CL-016 | 予約確定後、患者は自分の予約（ニックネーム＋電話番号／メールで照合）を再確認できる |
| FR-CL-017 | 予約料は本人確認書類の種類により異なる。保険証（健康保険証）を本人確認書類として登録した場合は3,000円、自由診療を希望し保険証以外（運転免許証／パスポート）で登録した場合は5,000円とする（匿名予約のデータ管理手数料は[9.3](#93-匿名予約完全匿名受診希望者向け)を参照） |
| FR-CL-018 | 診察開始時刻を過ぎてから10分以内に患者と連絡が取れない場合はキャンセル扱いとし、予約料は返金しない |
| FR-CL-019 | 患者の遅刻により診察開始が遅れて連絡がついた場合でも、診察終了時刻は延長せず、20分の診察時間は遅刻分だけ短縮される |
| FR-CL-020 | 診察が実施された場合は、診察料（保険診療または自由診療の料金）から予約時に支払った予約料（3,000円または5,000円）を差し引いた残額のみを徴収する |

**入力項目**

| 項目 | 必須 | 備考 |
|---|---|---|
| ニックネーム | ○ | 一意 |
| 電話番号またはメール | ○ | 匿名予約（[9.3](#93-匿名予約完全匿名受診希望者向け)）の場合はメールアドレスのみで予約確定可（電話番号不要） |
| 本名・生年月日・住所 | △ | 非提示オプション選択時は不要 |
| 本人確認書類の写真（保険証／運転免許証／パスポートのいずれか1点） | △ | 非提示オプション選択時は不要。保険証か否かで予約料が変わる（FR-CL-017） |
| 家族人数 | ○ | オンライン診療・新得時間外外来診療は、同一症状の場合に限り家族の同時受診が可能（上限3名）。ニコニコドック・搬送は対象者1名につき1枠 |
| 診療種別 | ○ | オンライン診療／新得時間外外来診療／ニコニコドック／搬送 |

**必須注意書き**

- 家族の同時受診は同一症状の場合に限り、オンライン診療・新得時間外外来診療ともに最大3名まで（詳細は[9.4](#94-同意書受診種別ごと)の同意書）
- 予約料は本人確認書類により異なる：保険証登録者3,000円／自由診療（保険証以外の書類）登録者5,000円（匿名予約は[9.3](#93-匿名予約完全匿名受診希望者向け)を参照）
- 診察開始から10分以内に連絡が取れない場合はキャンセル扱いとなり、予約料は返金しない
- 遅刻しても診察終了時刻は延長されず、20分の診察時間が遅刻分だけ短縮される
- 診察が実施された場合は、診察料から予約料を差し引いた残額のみを徴収する

## 9.3 匿名予約（完全匿名受診希望者向け）

個人情報の非提示オプション（[9.6](#96-個人情報非提示オプション)）を選択した患者に適用するフロー。

| ID | 要件 |
|---|---|
| FR-CL-021 | 非提示オプションを選択した場合、国内外の医療保険（国民健康保険・一般旅行保険等）を一切利用できないことを明示し、同意を得る |
| FR-CL-022 | 院内に個人情報を一切残さないためのデータ管理手数料60,000円が必要であることを明示し、同意を得る |
| FR-CL-023 | 利用時間中、職員以外がクリニックに入室しないよう配慮すること（個室対応）を希望する場合、3時間あたり追加100,000円が必要であることを明示し、同意を得る（任意の追加オプション） |
| FR-CL-024 | データ管理手数料60,000円の支払いに同意した患者は、個室対応オプション（FR-CL-023）の有無にかかわらず、他の患者と同様に予約手続き（時間枠選択・同意チェック・登録）へ進める |
| FR-CL-025 | 匿名予約は、ニックネームとメールアドレスの組み合わせのみで予約を確定できる（本名・電話番号・住所・本人確認書類の入力は不要） |
| FR-CL-026 | メールアドレス登録時、当該アドレスで連絡を受信できることを患者自身が確認・承認した上で登録を進める |

## 9.13 リピート患者の入力補助

[9.2 患者Web予約](#92-患者web予約)・[9.7 窓口予約](#97-紙予約取込窓口予約職員)の登録情報入力画面に適用する。

|---|---|

| FR-CL-131 | ニックネームと連絡先の組み合わせが過去の予約と一致する場合、直近の予約で入力された内容を候補として1件提示する |

| FR-CL-135 | 候補の自動入力は[9.4 同意書](#94-同意書受診種別ごと)の同意チェックを省略するものではなく、診療のたびに改めて同意を得る |
| FR-CL-136 | ニックネームは連絡先とセットで管理し、同一ニックネーム・同一連絡先の再入力は同一患者の再来院とみなす（別の連絡先による同一ニックネームの新規登録は[9.5](#95-ニックネーム)のFR-CL-051の重複ルールに従う） |
