# 6. 設計原則

医療記録の**可読性・入力負担最小化・医療安全**を核に、簡易な構成であっても以下の安全性・真正性・継続性に関する要件は省略しない。

## 基本方針

- 診療記録は、誰が、いつ、何を記録または変更したか確認できること。
- 一度確定・保存された診療記録は直接上書き削除せず、訂正履歴を残すこと。
- 患者カルテを開いている間は、すべての画面で患者ヘッダー（患者基本情報）を画面上部に固定表示すること。
- 診療情報、個人識別情報（PII）、連絡先、画像および動画を機微情報として取り扱うこと。
- アクセス制御、認証、暗号化、バックアップ、監査ログを必須機能とすること。

## 重要設計原則（必須）

| 項目 | 要件 |
|---|---|
| 確定済み記録を上書きしない | 確定済みの診療記録は直接編集・上書きせず、訂正記録または新しい版を追加する。訂正前の内容、訂正後の内容、訂正理由、訂正者、訂正日時を保持する。 |
| 誰が閲覧・変更したかを残す | 患者情報・診療記録・画像・動画の閲覧、登録、変更、確定、訂正、無効化、ダウンロード等を監査ログへ記録する。一般ユーザーは監査ログを変更・削除できない。 |
| 患者取り違えを防止する | 患者カルテを開いている間はID、氏名、カナ、性別、生年月日、年齢等を画面上部（患者ヘッダー）に固定表示する。 |
| 暗号化とバックアップを行う | 患者基本情報、診療記録、PII、画像・動画・添付文書およびバックアップを暗号化して保存し、定期的にバックアップと復元テストを行う。 |
| 個人情報を安全に管理する | 電子カルテに一時保存する本名・生年月日・住所・保険証番号は、受診完了日から**2ヶ月**で自動パージする。非提示オプション選択時はこれらのPIIを最初から一切保存しない。 |

これらは、簡易的なシステムであっても省かない設計とする。
