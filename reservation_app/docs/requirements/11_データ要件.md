## 予約料・PIIの扱い（種別横断ルール）

| 区分 | 予約料 | PII |
|---|---|---|
| 保険証を本人確認書類として登録 | 3,000円（受診時に診察料から差引） | 一時保存（2ヶ月でパージ） |
| 自由診療・保険証以外の書類で登録 | 5,000円（受診時に診察料から差引） | 一時保存（2ヶ月でパージ） |
| 非提示オプション（匿名予約） | データ管理手数料60,000円＋任意で個室対応100,000円/3h | 最初から非保存 |

## 保持・削除

| データ | ルール |
|---|---|
| PII（非提示オプション以外） | 受診完了から2ヶ月 → パージ（ロールに関わらず物理削除、職員・システムエンジニア画面からも参照不可） |
| 本人確認書類の写真 | PIIに準じ受診完了から2ヶ月でパージ |
| 非提示オプション利用者のPII | 最初から非保存（対象外） |
| ニックネーム | 恒久（再利用防止） |
| 経過記録 | 監査証跡付きで保持 |
| システムエンジニアによるマスタ管理操作ログ | 監査ログとして保持 |
| 搬送予約データ（連絡先・フライトチケット写真等） | 保持期間は別途確定する（未確定事項） |
