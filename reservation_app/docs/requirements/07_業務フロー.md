# 7. 業務フロー

## 予約〜受診〜パージ

1. 職員：月次カレンダーで枠をアクティベート（デフォルト非公開）
2. 一般：Web予約 ／ 職員：紙予約表（写真）＋手入力
3. 予約確定（予約料5,000円・返金不可）
4. 電子カルテで受診登録・SOAP記録・検査参照
5. 職員：予約一覧で「受診完了」を記録 → PII保持2ヶ月起算
6. 受診完了から2ヶ月後：PIIを自動パージ

## 電子カルテ操作の詳細（参考）

### 初診患者

1. 患者検索で既存患者がいないことを確認
2. 予約データから患者ヘッダー（ID・氏名・カナ・性別・生年月日・主病名・担当医・アレルギー・禁忌）を登録
3. 受診登録（診察方法：クリニック/巡回/訪問/オンライン）
4. SOAP（S/O/A/P）で経過記録を作成
5. 記録者情報（ログインユーザー）とともに保存

### 再診患者

1. 患者検索またはカレンダーから対象患者を選択
2. 患者ヘッダーで本人確認（アレルギー・禁忌バッジを確認）
3. 受診履歴・前回のSOAP記録を確認
4. 前回記録コピーまたは定型文テンプレートを使用して新しい経過記録を作成
5. 記録を保存（更新履歴に作成者・更新者・日時を記録）
